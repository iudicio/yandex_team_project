# Решения, риски и открытые вопросы

## 1. Принятые решения

| ID | Тема | Решение | Основание |
|---|---|---|---|
| ADR-01 | Сетевой API | Использовать актуальный Diploma proxy, не прямой HH API. | Текущая документация API и корневое ТЗ. |
| ADR-02 | Авторизация | `Authorization: Bearer <token>`; единый interceptor. | Live smoke 11.08.2026: raw → 401, Bearer → 200; web-пример устарел. |
| ADR-03 | Debounce | 2000 мс. | Корневое ТЗ и критерии имеют приоритет над старыми screen-файлами с 300 мс. |
| ADR-04 | UI stack | XML только для NavHost/BottomNavigationView; Fragment-hosted ComposeView, Composable, MaterialTheme и StateFlow для содержимого экранов. | Явные критерии учебной приёмки: SingleActivity + Navigation Component + BottomNavigationView, остальной UI через ComposeView. |
| ADR-05 | Scope третьей сдачи | В PR #12 включаются Epic 4–5, в том числе география; Epic 0–3 уже находятся в `main` и не должны повторяться в PR-diff. | Уточнённый scope `iteration_3_review`. |
| ADR-06 | Избранное | Room хранит полный snapshot деталей для офлайн-просмотра. | Требование списка и деталей без сети. |
| ADR-07 | Пагинация | Поиск — обязательная страница по 20; локальная пагинация избранного не входит в MVP. | Корневое ТЗ и критерии. |
| ADR-08 | Архитектура | Один `app`-модуль, слои Data/Domain/Presentation/UI, пакеты фич внутри Presentation/UI. | Достаточно для масштаба и соответствует критериям. |
| ADR-09 | UI source of truth | Точные токены и layout берутся только из Figma; значения не угадываются. | Предотвращение расхождений макета и ресурсов. |
| ADR-10 | Apply | Видима при наличии любого параметра или неприменённого изменения, включая reset; Back не запускает повторный поиск. | Покрывает критерий Epic 4 и screen-spec. |
| ADR-11 | Название стартовой вкладки | Пользовательская подпись — «Главная», внутреннее имя фичи — Search/«Поиск». | Подтверждённый текущий Figma canvas; ТЗ описывает назначение как поиск. |

## 2. Известные расхождения источников

| Расхождение | Используемая трактовка |
|---|---|
| Старые материалы описывают прямой HH API и `HH-User-Agent`, а страница proxy показывает raw Authorization. | Использовать proxy-поля `url`, `skills`, `parentId`, но фактически проверенный Bearer-заголовок. |
| Старые подсказки требуют `per_page=20`, proxy его не документирует. | Не отправлять `per_page`; проверить фактические 20 в E0-08. |
| Старый экран поиска упоминает debounce 300 мс. | Использовать 2000 мс. |
| Старые материалы делают отрасли деревом. | Актуальный `/industries` — плоский список. |
| Старые материалы могут показывать favorite/remove прямо в карточке списка. | Обязательный toggle — только на деталях, пока Figma не подтвердит большее. |
| Условия для команды из трёх допускают не сдавать географию, но текущий scope её включает. | Epic 5 реализуется и проверяется вместе с Epic 4 в PR #12. |

## 4. Реестр рисков

| Риск | Вероятность/влияние | Предупреждение | Реакция |
|---|---|---|---|
| Репозиторий не содержит стартового Android-шаблона | Высокая/высокое | E0-02 первым blocker | Импортировать актуальный официальный шаблон, не собирать инфраструктуру фич до запуска skeleton. |
| Утечка токена | Средняя/критическое | `.gitignore`, empty-token CI artifact, отдельный защищённый API smoke, redacted logs, review checklist | Немедленно отозвать/заменить токен и очистить всю Git-историю по согласованной процедуре. |
| Несогласованные модели Search/Details/Favorites | Средняя/высокое | E0-03, E1-01, ownership общих моделей | Отдельный contract PR до параллельных потребителей. |
| Конфликты nav graph, DI, Room schema | Высокая/среднее | Один владелец каждого общего файла | Последовательный merge, feature-specific DI-файлы. |
| UI блокируется незавершённым Data | Средняя/среднее | Сначала interfaces/fakes/UI state contract | UI работает с fake, затем заменяется binding в малом интеграционном PR. |
| Запоздалый поиск перетирает свежий | Средняя/высокое | generation/job cancellation test | Не принимать ответ отменённой generation. |
| Paging дублирует/теряет элементы | Средняя/высокое | `loadedPages`, set ID, reducer tests | Отдельный paging state и интеграционные тесты. |
| Неполный detail JSON вызывает crash | Высокая/высокое | Null-safe DTO/mapper fixtures | Скрывать отсутствующие блоки, логировать обезличенную причину mapping. |
| Офлайн-детали сохраняются не полностью | Средняя/высокое | Entity проектируется от полного domain model | In-memory Room round-trip test каждого поля. |
| Figma изменится во время разработки | Средняя/среднее | Ссылка на node и скриншоты в PR | Обновить токены/спецификацию отдельной задачей; не смешивать с фичей. |
| Расширенный scope Epic 4–5 ухудшит регресс Epic 1–3 | Средняя/высокое | Общие контракты Search/Filter, отдельные tests и финальный smoke всех сценариев | Не отмечать QA выполненным до проверки финального HEAD. |
| Большие PR замедлят ревью | Высокая/среднее | Лимит 5 SP/одна задача | Делить contract, implementation, UI и tests. |

## 5. Журнал новых решений

Для нового решения добавить строку:

```text
ADR-NN | дата | проблема | варианты | решение | последствия | участники
```

Решения, меняющие API/domain contract, Room schema, навигацию или обязательный scope, принимаются всеми тремя участниками до merge.
