## Scope diff PR

Epic 0 — это база из актуального `main`, а не часть изменений. Вкладки GitHub «Commits» и «Files changed» для PR #10 не должны содержать коммиты или файлы, относящиеся только к Epic 0.

### Epic 1 — поиск вакансий и экран команды

- Экран поиска является стартовым и доступен через корневую вкладку нижней навигации.
- Поле поиска поддерживает hint, очистку, IME action и debounce 2000 мс; пустой запрос не отправляется.
- Search API, DTO, Repository, Interactor и ViewModel разделены по слоям; DTO не выходят из Data.
- Реализованы initial/loading/content/empty/no-internet/server-error состояния.
- Результат содержит количество найденных вакансий, карточки, форматирование зарплаты и placeholder логотипа.
- Пагинация загружает следующую страницу у конца списка, не повторяет успешную страницу и не дублирует вакансии.
- Во время пагинации виден нижний progress; ошибка скрывает его и показывает требуемый Toast без потери списка.
- Экран «Команда» показывает статический список трёх реальных участников и доступен через BottomNavigationView.

### Epic 2 — детали вакансии

- ID вакансии передаётся из списков Search/Favorites navigation argument; нижняя навигация на деталях скрыта.
- Details API, null-safe DTO/domain mapping, Repository, Interactor и ViewModel реализованы по слоям.
- Реализованы loading/content/no-internet/not-found/server-error и повтор загрузки.
- Контент прокручивается; зарплата, компания, адрес/регион, опыт, занятость, график и HTML-описание отображаются по доступным данным.
- Пустые блоки навыков и контактов скрываются; отсутствующий или загружаемый логотип заменяется placeholder.
- Share открывает системный chooser, email — почтовый клиент, телефон — dialer; комментарий к телефону отображается.

### Epic 3 — избранные вакансии

- Favorite toggle на деталях отражает текущий статус и добавляет/удаляет вакансию.
- Room Entity/DAO/Database хранят полный snapshot, достаточный для списка и офлайн-деталей.
- Миграция Room 1→2 сохраняет legacy-строки Epic 0; schema экспортируется и migration-сценарий покрыт instrumentation-тестом.
- Repository и Interactor предоставляют add/remove/get/list/isFavorite; Favorites ViewModel наблюдает изменения.
- Экран избранного поддерживает loading/empty/content/database-error и переиспользует карточку вакансии.
- Список избранного доступен без сети; сохранённые детали открываются без сети, логотип допускает placeholder.
- Возврат и повторное открытие не показывают устаревший favorite state; удаление обновляет список.

### Epic 4 — фильтр «Отрасли и ЗП»

- Кнопка фильтра открывает экран настроек; bottom navigation на вложенных экранах скрыта.
- Зарплата принимает только целые числа; hint и clear-action зависят от значения.
- «Сбросить» видна при активных параметрах. «Применить» видна при любом активном параметре или если настройки отличаются от последних применённых; reset очищает все параметры и позволяет повторить запрос без фильтров.
- Industries API, DTO, Repository и Interactor изолированы по слоям; сетевая работа идёт не в main thread.
- Экран отраслей показывает loading/content/no-network/server-error/generic-error, локальный поиск, одиночный выбор и условную кнопку «Выбрать».
- SharedPreferences Repository/Interactor автоматически сохраняют и восстанавливают зарплату, отрасль и `only_with_salary`.
- Apply повторяет непустой поиск с актуальными параметрами; Back не перезапускает поиск; активный фильтр подсвечивает иконку.

### Epic 5 — фильтр «Место работы»

- Экран места работы открывает списки стран и регионов и показывает текущий выбор.
- Areas API, recursive DTO, Repository и Interactor выделяют страны по `parentId == null` и регионы по дереву `areas` вне main thread.
- Списки стран/регионов различают loading/content/no-network/server-error/generic-error; поиск региона локальный и регистронезависимый.
- Выбор страны ограничивает регионы; выбор региона автоматически выбирает его родительскую страну.
- «Выбрать» видна при стране или регионе; результат возвращается в общий экран фильтров.
- Страна и регион сохраняются в SharedPreferences; в поиск передаётся `area = regionId ?: countryId`.
