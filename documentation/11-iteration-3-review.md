# Iteration 3 Review — Epic 4 и Epic 5

Этот документ описывает PR `iteration_3_review → main`. К началу третьей итерации в `main` уже должны находиться принятые Epic 0–3. Поэтому вкладка GitHub Files changed в PR #12 должна показывать полную реализацию только Epic 4 «Отрасли и ЗП» и Epic 5 «Место работы», включая их необходимую интеграцию с поиском.

## Scope PR

### Epic 4 — фильтр «Отрасли и ЗП»

- Общая модель `FilterSettings`, query-параметры поиска и хранение настроек в SharedPreferences.
- Экран фильтра с отраслью, целочисленной зарплатой, checkbox «Не показывать без зарплаты» и условными действиями «Сбросить»/«Применить».
- Industries API, типизированные ошибки, Repository/Interactor/ViewModel и экран одиночного выбора отрасли с локальным поиском.
- Применение фильтров повторяет непустой поиск, reset позволяет повторить его без ранее применённых параметров, Back не запускает поиск автоматически.
- Активный фильтр отражается в иконке поиска; сохранённые параметры восстанавливаются после перезапуска.

### Epic 5 — фильтр «Место работы»

- Areas API и null-safe recursive DTO/domain-модель; страны определяются по `parentId == null`, регионы — по дереву `areas`.
- Экраны места работы, страны и региона с loading/content/no-network/server-error/generic-error состояниями.
- Без страны доступны все регионы; выбор страны ограничивает список, а выбор региона автоматически выбирает родительскую страну.
- Поиск региона выполняется локально и без учёта регистра; пустой результат показывает отдельное состояние.
- Страна и регион сохраняются вместе с остальными настройками; в поиск передаётся `area = regionId ?: countryId`, а пустой `area` не добавляется в URL.

### Допустимые изменения общих файлов

Для сквозной работы Epic 4–5 PR может изменять общие Search API/request, Search ViewModel/UI, DI, navigation arguments, resources и Manifest. Такие файлы относятся к третьей итерации только в части, необходимой для передачи `industry`, `salary`, `only_with_salary`, `area`, открытия экранов фильтров и корректного повтора поиска. Несвязанные изменения Epic 0–3 в scope не входят.
